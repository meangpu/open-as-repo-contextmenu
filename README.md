### open-as-git-repo

make it easy to do open file as repo by right click

### note for myself

install this first

```sh
npm install -g @vscode/vsce
```

to make local install package

```sh
vsce package
```

get PAT from https://dev.azure.com/ (top-right before my account icon)
to update do this

```sh
vsce login meangpu
vsce publish
```
